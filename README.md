# BMI Calculator – Python Project

## Beginner Version
A simple command-line BMI calculator:
- Takes weight and height
- Calculates BMI
- Shows category
- Handles invalid inputs

## Advanced Version (GUI)
Features:
- Tkinter-based GUI
- BMI calculation with live result
- Saves BMI data into bmi_history.txt
- Plots BMI history using Matplotlib

## Technologies Used
- Python
- Tkinter
- Matplotlib
- File handling
